🛠️ 小工具集合

5 个纯前端工具 · 打开即用 · 所有计算都在浏览器本地完成，数据不上传

🔧

进度文档解码 / 编码器

解码游戏进度文档为可读文本，支持修改后重新编码；可提取证明项、类型层证明项与排列表。

打开 v6 → 历史版本
∑

公式格式转换

自动识别 Markdown / LaTeX / MathML 公式标记，一键统一风格，实时预览。

打开 → 历史版本
␣

中西文间距自动格式化

在汉字与西文 / 数字之间自动补一个空格，公式与 [[...]] 内部内容原样保留。

打开 → 历史版本
🔄

文本替换工具

按顺序将左侧字符串替换为右侧字符串，规则列表可自由增删，实时预览替换结果。

打开 → 历史版本
📄

PDF 页面提取

上传 PDF，输入需要提取的页码（支持单页、逗号分隔与页码范围），下载处理后的新文件。

打开 → 历史版本
