## ZFC公理系统介绍
- ZFC 公理系统包含 10 个公理，为外延公理、分离公理、空集公理、配对公理、并集公理、幂集公理、无穷公理、替换公理、正则公理和选择公理，去掉选择公理的系统称为 ZF。由于空集公理实际上可以被分离公理推出，所以游戏里并未给出空集公理而是要求你把它当作定理来证明。（其实游戏里的替换公理也可以证明分离公理，请读者自行尝试）
- 在这些公理当中，外延公理介绍了集合相等的定义；此外，分离公理、配对公理、并集公理、幂集公理、无穷公理、替换公理和选择公理都介绍了构造集合的方式；而正则公理则禁止了病态集合（如 $x=\{x\}$）的存在。
## 外延公理与分离公理
### 外延公理
- 外延公理
- aExt:(∀x:(∀y:((∀z:¬(((z∈x)→(z∈y))→¬((z∈y)→(z∈x))))→(x=y))))
- 门是它的简化版
- .aext:(∀x:(∀y:((∀z:((z∈x)↔(z∈y)))→(x=y))))
- 简化流程
```
d aExt
d vvvd<>1 x y z z@x z@y
d vv<a5 1
d vv.t 2 0
```
压缩版证明
 ```
 ::vvvd<>1,vv<a5:aExt,vv.t
 ```
- 也是十分简单

## 序数系统
### 序数的介绍
- 其实在拿完指南针后就可以来了 但在ZFC后我们不得不说了
- 序数是自然数的推广 序数不仅有自然数 还包含多种无穷大 要从有限突破到无限 需要借助极限的力量

- 到达一个序数有两种方式 一是取后继 二是取极限 后继就是下一个数 即+1 取"极限"进位则是把大于某个数的数视作无穷"ω"

### filter

并集公理后面的题目比较难, 需要下面的 filter 引理 (也可以到 ω³+ω²3+ω5+7 处解锁游戏提供的 .filter 引理)

filter 引理的大意是, 若存在集合 x, 和一个谓词 P(z) 满足 P(z) → z∈x, 那么存在唯一 y ⊆ x,
使得 P(z) ↔ z∈y, 即该谓词给出 z∈y 的充要条件. 用这个引理我们可以从 x 中过滤出子集 y, 这就是名字 filter 的由来.

filter 引理的存在性和唯一性两部分结论分别由 .asep 和 .aext 保证.
证明过程需要用局部变量, 以避免该变量在 $0 中自由出现.

sfilter:∃x:∀z:(#nf($0,x)→z∈x)⊢∃x:∀z:(z∈x↔#nf($0,x))
```
mcpt ($0>$1)>($2<>$1&$0)>($2<>$0) lfilter
hyp Ex:Vz:(#nf($0,x)>z@x)
v>u>v<<lfilter x z #nf($0,x) # z@x z@#
.asep x # z #nf($0,x)
v<a1 2 Vz:(#nf($0,x)>z@x) 
vc.Emp 1 3
.Emp 4 0
.Ee 5
.Ecn 6 x
```
sfilter!:∃x:∀z:(#nf($0,x)→z∈x)⊢∃!x:∀z:(z∈x↔#nf($0,x))
```
hyp Ex:Vz:(#nf($0,x)>z@x)
dE! x # Vz:(z@x<>#nf($0,x))
vv:>>v:#:.<>s,.<>t,.&m2 x # z z@x #nf($0,x) z@#
