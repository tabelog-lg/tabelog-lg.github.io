## List

$\List$类型有两个构造子：
$\nil:\List\ ?1$空列表
$\cons:?1\ra \List\ ?1\ra\List\ ?1$往列表尾部添加元素

两个门都可以用$\nil$开，空列表的类型是任意的$\List\ ?0$


$${\rm{fillList}}：=\L a:\Uz.\L x:a.\ind{nat}\ (\L y:\nat.\List\ a)\ \nil\ (\ \L y:\nat.\L z:\List\ a.\cons\ x\ z)$$

解锁Option类型

$${\rm{lastList}}:=\L a:\Uz.\ind{List}\ (\L l:\List\ a.\Option\ a)\ \none\ (\L\ x:a.\L y:\List\ a.\L z:\Option\ a.\some\ x)$$

$${\rm{firstList}}:=\L a:\Uz.\ind{List}\ (\L x:\List\ a.\Option\ a)\ \none\ (\L x:a.\L y:\List\ a.\L z:\Option\ a.\ind{List}\ (\L x:\List\ a.\Option\ a)\ (\some\ x)\ (\L p:a.\L q:\List\ a.\L r:\Option\ a.z)\ y)$$

$${\rm{lenList}}:=\L a:\Uz.\ind{List}\ (\L x:\List\ a.\nat)\ 0\ (\L x:a.\L y:\List\ a.\L z:\nat.\suc\ z)$$

$${\rm{invList}}:=\L a:\Uz.\L b:\List\ a.\ind{List}\ (\L x:\List\ a.(\List\ a)\ra(\List\ a))\ (\L x:\List\ a.x)\ (\L x:a.\L y:\List\ a.\L z:(\List\ a)\ra(\List\ a).\L w:\List\ a.z\ (\cons\ x\ w))\ b\ \nil$$

$${\rm{sumList}}:=\ind{List}\ (\L x:\List\ \nat.\nat)\ 0\ (\L x:\nat.\L y:\List\ \nat.\L z:\nat.\rm{add}\ x\ z)$$

$${\rm{mapList}}:=\L a:\Uz.\L b:\Uz.\L f:a\ra b.\ind{List}\ (\L x:\List\ a.\List\ b)\ \nil\ (\L x:a.\L y:\List\ a.\cons\ (f\ x))$$

$${\rm{count\_0}}:=\ind{List}\ (\L x:\List\ \nat.\nat)\ 0\ (\L x:\nat.\L y:\List\ \nat.\L z:\nat.\ind{\nat}\ (\L a:\nat.\nat)\ (\suc\ z)\ (\L a:\nat.\L b:\nat.z)\ x)$$

$${\rm{del\_0}}:=\ind{List}\ (\L x:\List\ \nat.\List\ \nat)\ \nil\ (\L x:\nat.\L y:\List\ \nat.\L z:\List\ \nat.\ind{nat}\ (\L a:\nat.\List\ \nat)\ z\ (\L a:\nat.\L b:\List\ \nat.\cons\ x\ z)\ x)$$

## Even

[怎么过度到W类型？]: #Even
[List做完解#W门吧]: #

- Even意为偶数 该类型是递归定义的
  有一个初始构造子$\even0:\Even\ 0$
  和一个递归构造子$\evenss$
  其类型为 $\evenss:\P{x:\nat}(\Even\ x)\ra(\Even\ (\suc\ (\suc\ x)))$
- 第一道题 $\Even\ 0$ 十分简单
  因为在上面那段文字里就有答案
- 第二道题 $\Even\ 4$ 也很简单
  使用 $\evenss$ 即可
  (答案:$\evenss\ 2\ (\evenss\ 0\ \even0)$)
- 下一题 $\P{x:\nat}\Even\ (\double\ x)$ 也很简单
  对x进行归纳,0的时候用$\even0$,$\suc$到时候用$\evenss$
  ```
  intro x
  destruct x
  apply even0
  apply evenss (double x) x_
  qed
  ```
- 下一题 $\P{x:\Even\ 0}\eq x \even0$ 有点难
  这个命题是在证明 $\Even\ 0$ 的构造子只有一个
  如果你直接使用证明策略你会发现在```intro x```后,你会发现无法进行下一步
  而有一种奇妙的做法就是用$\ind{nat}$定义一个函数
  $f:\P{x:\nat}\P{p:\Even\ x}\ind{nat}\ (\L{x:\nat.}\P{p:\Even\ x}\Uz)\ (\L{p:\Even\ 0}.(\eqs{p}{\even0}))\ (\L{x:\nat.}\L{p:(\Even\ x)\ra\Uz.}\L{q:\Even\ (\suc\ x).}\True)\ x\ p$
  ```
  intro x
  intro p
  destruct p
  rfl
  exact true
  qed
  ```
  $f\ 0$就是题目的答案
  解锁小于$ω$的基数$\rm{Aleph}$($א$)
- 下一题 $\not(\Even\ 1)$ 和 $\not(\Even\ 11)$ 和 $\not(\Even\ 111)$ 有点难
  我们可以构造一个函数他在奇数的时候输出$\False$ 
  偶数的时候输出$\True$
  定义$\rm{isEven\_Odd}:\ind{nat}\ (\L{x:\nat.}\Uz\X\Uz)\ (\True,\False)\ (\L{n:\nat.}\L{x:\Uz\X\Uz.}(\pr1\ x,\pr0\ x))$
  引理$\rm{is\_Odd}:\P{n:\nat}(\Even\ n)\ra(\pr0\ (\rm{isEven\_Odd}\ n))$
  ```
  intro n
  intro h
  expand isEven_Odd
  destruct h
  exact true
  apply h_
  qed
  ```
  $\rm{is\_Odd}$输入一个奇数x,他会输出$\not(\Even\ x)$
- 下一题 $\P{x:\nat}(\Even\ x)\ra(\Even\ (\pred\ (\pred\ x)))$ 十分简单
  ```
  intro x
  intro h
  destruct h
  apply even0
  apply h_e
  qed
  ```
  保存为$\rm{evenpp}$
- 下一题 $\P{x:\nat}(\Even\ x)\ra(\S{y:\nat}\eq{(\double{y})}{x})$ 也很简单
  ```
  intro x
  intro h
  destruct h
  ex 0
  rfl
  destruct h_
  ex succ h_0
  rwb h_1
  rfl
  qed
  ```
- 下一题 $\P{x:\nat}\P{y:\nat}(\Even\ x)\ra(\Even\ y)\ra(\Even\ (\add{x}{y}))$ 也很简单
  ```
  intro x
  intro y
  intro h
  intro h'
  destruct h'
  apply h
  apply evenss (add x h'') h'_
  qed
  ```
  保存为$\rm{even\_add}$
- 下一题 $\P{x:\nat}(\Even\ x)\ra(\not(\Even\ (\suc\ x)))$ 也很简单
  ```
  intro x
  intro h
  expand not
  intro h'
  destruct h
  apply isOdd 1 h_h'
  apply h_
  apply evenpp (succ (succ (succ h))) h_h'
  qed
  ```
- 下一题 $\P{x:\nat}(\not(\Even\ x))\ra(\Even\ (\suc\ x))$ 有点难
  先证明引理$\rm{even\_or\_succ}:\P{x:\nat}(\Even\ x)+(\Even\ (\suc\ x))$
  ```
  intro x
  destruct x
  left
  apply even0
  destruct x_
  right
  apply evenss x x_l
  left
  apply x_r
  qed
  ```
  开始证明原命题
  ```
  intro x
  intro h
  destruct x
  hyp False
  apply x_h
  apply even0
  destruct hyp
  hyp (Even x)+(Even (succ x))
  apply even_or_succ x
  destruct hyp
  apply evenss x hypl
  hyp False
  apply x_h
  apply hypr
  destruct hyp
  qed
  ```
  保存为$\rm{even\_not\_succ}$
- 下一题 $\P{x:\nat}(\Even\ (\suc\ (\suc\ x)))\ra(\Even\ x)$ 十分简单
  ```
  intro x
  apply evenpp (succ (succ x))
  qed
  ```
- 下一题 $\P{x:\nat}\P{y:\nat}(\not(\Even\ x))\ra(\not(\Even\ y))\ra(\Even\ (\add{x}{y}))$ 有点难
  ```
  intro x
  intro y
  intro h
  intro h'
  hyp Even (succ x)
  apply even_not_succ x h
  hyp Even (succ y)
  apply even_not_succ y h'
  hyp Even (succ (add (succ x) y))
  apply even_add (succ x) (succ y) hyp hyp'
  hyp Even (succ (succ (add x y)))
  rwb nat_succ_add x y
  apply hyp''
  apply evenpp (succ (succ (add x y))) hyp'''
  qed
  ```
