## 自然数(皮亚诺,你被解雇啦!)
我们将在集合论框架下实现皮亚诺公理系统
空集相当于0
后继S(x)相当于xU{x}
要将ω与ℕ两者等同就要重新“证明”5个公理
- spn1:({}∈ω)
  ```
  d domega
  d <a4 0 {}
  d :<.<>2:v>.&1,mp 1
  m spn1
  ```
- spn2:(∀n:((n∈ω)→((n∪{n})∈ω)))
由omega定义可知
x属于omega等价于x属于任意一个归纳集S
对xU{x}也同理
x∈omega推出x∈S
归纳集定义可知x∈S能推出xU{x}@S
  ```
  d ::domega,v<.<>1,vcv.&m1
  d vcvca4 n n@omega x {}@x y (y@x)>((yU{y})@x) n
  d :domega,v<.<>2
  d <a6 2 n
  d v<a4 3 nU{n}
  d ::vcvccmp,vcv.&m2,v.t 1 0 4
  m spn2
  ```
- spn3:(∀x:¬((x∪{x})={}))
  ```
  d v::dU:::a7,:d{.},<<.<>2,.|2,<<.<>2,s=n{} x x x
  m spn3
  ```
- spn4:(∀x:(∀y:(((x∪{x})=(y∪{y}))→(x=y))))
  从前提易得x∈yU{y}
  因此要么x=y要么x∈y
  正则公理可证x∈y不可能
  因此x=y得证
  因为x跟y的地位对称
  所以同样可得到y∈x
  即:若¬x=y,有x∈y∧y∈x成立
  易证集合{x,y}违背了正则公理
  说明假设~x=y错误
  ```
  d vvvd& x y z z@{x,y} (zI{x,y})={}
  d :vva1,::vv.<>rE,vv<.<>1,vvmp 0 (xU{x})=(yU{y})
  d vvvd{..} x y z z x y
  d :vva1::vvv<.<>1,vv<a1,vvmp 2 (xU{x})=(yU{y}) ~(x=y)
  d vv>.=s x y y x
  d :vva1:vv<.a30,vvmp 4 (xU{x})=(yU{y})
  d vv.<>i x y y@x
  d vvd{.} x y y x
  d :vva1:vv.<>r|,vvmp 6 7 (xU{x})=(yU{y})
  ```
