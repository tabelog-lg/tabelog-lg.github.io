## 起点
在消耗了100μg后，我们可以解锁五条皮亚诺公理`apn1`-`apn5`和10以内的数字定义
``` txt
apn1:(0@N)
0是自然数

apn2:(Vx:((x@N)>(S(x)@N)))
自然数的后继是自然数

apn3:(Vx:~(S(x)=0))      
对于任意数x，x的后继数不为零（保证0是第一个自然数）

apn4:(Vx:(Vy:((S(x)=S(y))>(x=y))))
后继数相同的数相同（避免分支）

apn5:(#rp(#nf($0,x),$1,0)>((Vx:((x@N)>(#rp(#nf($0,x),$1,x)>#rp(#nf($0,x),$1,S(x)))))>(Vx:((x@N)>#rp(#nf($0,x),$1,x)))))
数学归纳法
```

## 侧翼
### `spa0`
- `~(1=0)`
###### 引理`.=s`
- `($0=$1)⊢($1=$0)`
``` txt
hyp $0=$1
a8 $0 $1 $0=$0 1
mp 1 0
a7 $0
mp 2 3
```
###### 引理`.=t`
- `($0=$1),($1=$2)⊢($0=$2)`
```txt
hyp $0=$1 $1=$2
<<a8 1 0 -1
```
##### 证明
- 接下来我们的思路是根据`apn3`，把其中的`S(x)`换成`1`
- 首先利用`a4`把任意变量`x`取值`0`得到`~(S(0)=0)`
``` txt 
apn3
a4 x ~(S(x)=0) 0
mp 1 0
```
- 然后用`a8`将`S(0)`换成`1`
```txt
a8 S(0) 1 ~(S(0)=0) 0
d1
.=s 4
mp 3 5
mp 6 2
```
 *通过这里后便能解锁加法和乘法公理*

## 分支A：加法交换律
### 左零律`Lz`
- `(Vx:((x@N)>((0+x)=x)))`
##### 证明
- 先在归纳法末尾凑出我们想要的形式
``` txt
(((0+0)=0)>
((Vx:((x@N)>(((0+x)=x)>((0+S(x))=S(x)))))>
(Vx:((x@N)>((0+x)=x)))))
```
- 然后以假设`x@N`和`(0+x)=x`构造出`(0+S(x))=S(x))`作为中间定理`Mid`，此时`v>>Mid`即是我们需要的中间条件`Vx:((x@N)>(((0+x)=x)>((0+S(x))=S(x))))`
- 以下证明过程是将`Mid`相关内容整合进`Lz`后的,以空行分块
``` txt
apn1
d+1 0
mp 1 0
apn5 (0+y)=y y
mp 3 2

v.i x (0+x)=x
vc<a8 5 (0+S(x))=S(0+x) 0
v<a1 6 x@N
vd+2 x 0 x
vapn1 x
vmp 8 9
vc<a1 10 (0+x)=x
vccmp 7 11

mp 4 12
```

### `spa6`
- `($0@N)>($0*1=$0)`
  它前面的门很简单 `vd*1` 即可
  这个命题稍微有点小坑
  如果你直接`d*2`去证 那么最后结果会出现`(#rp(($x * S(0)), S(0), 1) = #rp($x, S(0), 1))` 那是因为$x可能为S(0) 那应该怎么办呢

  ```txt vapn1 x
  v<<a8 2 1 0

  vc<<a8 4 3 0
  Lz
  vcl2 5 6
  <a4 7 $x
  ```
