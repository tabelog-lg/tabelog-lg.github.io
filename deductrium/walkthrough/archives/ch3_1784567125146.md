# Deductrium 攻略第三章 皮亚诺算数（PA）
## 前言
欢迎斥了100μg巨资的你来到形式算数的世界，

皮亚诺公理由意大利数学家朱塞佩·皮亚诺于1889年提出，用于建立自然数的公理化体系 。其核心思想是通过五条公理定义自然数集合及其基本运算规则。在此之后运算符号抛弃了自然意义，应作为纯粹符号来看待。

## 起点
在消耗了100μg后，我们可以解锁五条皮亚诺公理`apn1`-`apn5`和10以内的数字定义
``` txt
apn1:(0@N)
0是自然数

apn2:(Vx:((x@N)>(S(x)@N)))
自然数的后继是自然数

apn3:(Vx:~(S(x)=0))      
对于任意数x，x的后继数不为零（保证0是第一个自然数）

apn4:(Vx:(Vy:((S(x)=S(y))>(x=y))))
后继数相同的数相同（避免分支）

apn5:(#rp(#nf($0,x),$1,0)>((Vx:((x@N)>(#rp(#nf($0,x),$1,x)>#rp(#nf($0,x),$1,S(x)))))>(Vx:((x@N)>#rp(#nf($0,x),$1,x)))))
数学归纳法
```


## 侧翼
### `spa0`:
- `~(1=0)`
###### 引理`l1`
- `($0=$1)⊢($1=$0)`
``` txt
hyp $0=$1
a8 $0 $1 $0=$0 1
mp 1 0
a7 $0
mp 2 3
```
##### 证明
- 接下来我们的思路是根据`apn3`，把其中的`S(x)`换成`1`
- 首先利用`a4`把任意变量`x`取值`0`得到`~(S(0)=0)`
``` txt 
apn3
a4 x ~(S(x)=0) 0
mp 1 0
```
- 然后用`a8`将`S(0)`换成`1`
```txt
a8 S(0) 1 ~(S(0)=0) 0
d1
l1 4
mp 3 5
mp 6 2
```
 *通过这里后便能解锁加法和乘法公理*

### `spa2`:
- `(1+0)=1`
##### 证明
- 用`a8`将加法公理中的`x`替换为`1`即可
